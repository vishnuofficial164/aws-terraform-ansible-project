# AWS Infrastructure Automation Using Terraform and Ansible

## Project Overview

This project demonstrates Infrastructure as Code (IaC) using Terraform and configuration management using Ansible on AWS.

## Tools Used

- AWS EC2
- VPC
- Terraform
- Ansible
- Linux

## Tasks Performed

- Provisioned AWS EC2 instances using Terraform
- Configured VPC and Security Groups
- Automated infrastructure deployment
- Installed and configured Nginx using Ansible
- Managed server configuration through automation

## Benefits

- Infrastructure as Code
- Reduced manual configuration
- Faster deployment process
- Consistent infrastructure provisioning
